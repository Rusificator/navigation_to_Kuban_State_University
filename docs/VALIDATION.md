# Выполненные проверки и границы результата

Дата: 19.10.2026. Автоматические тесты запускаются `npm test` (Vitest), типизация и production bundle - `npm run build`.

В текущем наборе **50 тестов**:

- Сохранение 969 исходных помещений, всех узлов/рёбер и добавляемых исходным кодом входов.
- Поиск латиницей и кириллицей, одинаковые названия, фильтры; полнота RU/EN.
- Реальный путь от главного входа до А421, маршрут в ту же точку, отсутствие входа, изолированные узлы и альтернативные двери Н401.
- Выбор минимального пути среди нескольких входов, направленные/закрытые рёбра, подтверждённый лифт для доступного профиля.
- Проверка связности и суммы стоимостей для широкой выборки реальных целей.
- Качество и возраст GPS, необследованная привязка и перенос ошибки измерений.
- Завершение отложенной подписки после отмены, устаревшие permission-результаты и callbacks.
- Поиск → карточка → избранное; поиск → маршрут → ручное прохождение → четвёртый этаж.
- RU/EN и тема; повтор GPS после отказа; клавиатурный поиск и диалог сообщения об ошибке.
- Проверка пакетов: отсутствующие ссылки, повторные ID, отрицательная стоимость и внедрение разметки в SVG.
- Границы всех корпусов и координата лестничной площадки на принимающем этаже.
- Дополнительные языки данных, подстановка отсутствующих переводов, отклонение нестроковых переводов и маршруты/фильтры для этажа 0.

DOM-тесты используют настоящие данные и Router, но заменяют Three.js renderer заглушкой. Это проверка поведения интерфейса, не его пикселей и не производительности GPU.

Проверены production-сборка TypeScript/Vite и генерация автономного HTML. Android/iOS проекты созданы Capacitor; `native:sync` копирует сборку и подключает плагины. Конфигурация платформ выполнялась повторно для проверки идемпотентности.

## Не выполнено

| Проверка | Почему результат не заявляется |
|---|---|
| APK/AAB/IPA и установка на телефон | В среде нет полного Android SDK и macOS/Xcode; подписи не предоставлены |
| Визуальная браузерная приёмка и FPS/память WebGL | Браузерный процесс не запустился в доступной среде; DOM-тесты не заменяют браузер |
| Реальная геолокация в кампусе | Нет устройства на территории университета |
| Современная версия Google Play | Карточка недоступна для получения проверяемого официального бинарника |
| Актуальность кабинетов и физическая доступность | Требуется обследование и подтверждение КубГУ |

Для повторяемой браузерной проверки на рабочей машине:

```sh
npm run build
npx playwright install chromium
npm run test:browser
```

Скрипт проверяет основные действия на ширинах 1440, 390 и 320 px, отсутствие горизонтального переполнения и необработанных ошибок; создаёт локальные изображения для ручного просмотра. Сам скрипт подготовлен, но его прохождение в этой среде не заявляется.

Изменения карты повторно проверять через импорт-аудит и реальную прогулку; успешные тесты графа подтверждают его внутреннюю согласованность, но не физическое существование двери.

Ревизия 0.2: дополнительно проверены единственные карточки 215/109С, переход главный–Л в обе стороны, новые наружные карточки, OSM-ссылки, безопасный импорт и отсутствие ложной подсветки. Подробнее: [REVISION-0.2.md](REVISION-0.2.md).

Повторный импорт 19.10.2026: байтово совпали campus.json и оба аудита. Выполнен статический рендер настоящих компонентов SVG в обеих темах; вручную просмотрены общий светлый план, переход главный–Л и тёмная GPS-карта. Это не браузерный снимок и не проверка WebGL.
