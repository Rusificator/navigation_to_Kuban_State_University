# КубГУ Навигатор

Текущая версия: **0.2.0**. [Изменения и проверка источников](docs/REVISION-0.2.md).

Исправлены единственный мобилизационный отдел **215**, читальный зал **109С** и внутренний переход главный–Л через второй этаж. Добавлены стадион, общежития и другие ориентиры территории.


Предварительная версия 0.2.0, 19 октября 2026 года. React + TypeScript + Capacitor для Android и iOS, SVG для поэтажной карты, Three.js для объёмного просмотра. Схемы и маршруты работают локально. Это рабочая основа приложения с перенесёнными данными, а не подтверждённая на местности навигационная система.

## Запуск

Нужен Node.js 22.12+; проверено с Node 24.19. Зависимости зафиксированы в `package-lock.json`.

```sh
npm ci
npm run dev
```

Откройте адрес из терминала. Для законченной веб-сборки:

```sh
npm test
npm run build
npm run preview
```

Для автономной демонстрации: `npm run build:demo`, затем открыть `demo/index.html`. Карты, поиск, маршруты, RU/EN и темы не требуют сети. Для проверки GPS и буфера обмена предпочтителен `localhost` либо HTTPS; доступность этих API при открытии `file://` зависит от браузера. Веб-версия не устанавливает service worker: для гарантированной автономности используйте единый HTML или нативную сборку.

## Что можно проверить

1. Найдите `А421` или `A421` через поиск. Откройте карточку и добавьте её в избранное.
2. Нажмите «Маршрут сюда». По умолчанию начало - главный вход; обе точки можно заменить или поменять местами.
3. Постройте маршрут, начните путь и отмечайте шаги. Карта переключается на этаж соответствующего шага. Можно вернуться назад или изменить маршрут.
4. Переключите 2D/3D. В 3D доступны вращение, приближение, обзор всех этажей и разнесение этажей. При отсутствии WebGL предлагается 2D.
5. В настройках выберите светлую, тёмную или системную тему и русский/английский язык.
6. Включите GPS явно. Геопозиция появляется на географическом слое территории при приемлемой свежести и принадлежности кампусу. Видна область погрешности.
7. Импортируйте собственный пакет JSON в настройках. Он действует до закрытия/перезагрузки приложения. Избранное разделяется по ID кампуса.

А421 отнесена к библиотечному блоку по исходной геометрии. Буква в номере не определяет принадлежность корпуса.

## Платформы

```sh
npm run native:sync
npx cap open android
# на macOS:
npx cap open ios
```

`native:sync` собирает веб-часть, синхронизирует Capacitor и идемпотентно применяет разрешения, deep links, системные переводы, версии и iOS privacy manifest. Иконки уже созданы; пересоздать их можно командой `npm run icons`.

Android: minSdk 24, compile/targetSdk 36, актуальный Android System WebView. Нужны Android Studio 2025.2.1+ и SDK 36; используйте JDK из Android Studio. iOS: минимальная версия проекта 16.0, macOS и Xcode 26+. Базовая зависимость Capacitor поддерживает более раннюю iOS, но проект сознательно выбирает iOS 16 для согласованности с веб-интерфейсом.

В Android Studio: Build APK(s) для локального тестирования; для магазина нужен отдельный release signing. В Xcode выберите Team и устройство/симулятор. Идентификатор проекта `org.kubsu.navigator.next` предварительный. Он не выдаётся за доступ к существующему приложению `ru.initlab.pathfinderkubsu`. Для обновления прежнего приложения потребуются права на его записи и подписи.

**В этой среде выполнены веб-сборка и Capacitor sync. APK/AAB/IPA не скомпилированы и не подписаны.** Android SDK/Xcode и рабочий браузер с GPU здесь недоступны для полной проверки.

## Статус

| Возможность | Состояние |
|---|---|
| 5 этажей, 969 исходных помещений/зон, 8 групп корпусов и 8 наружных мест | Перенесены из APK без потерь геометрии помещений |
| Поиск, фильтры, избранное, A→B | Реализованы; имена не используются как уникальные ключи |
| Пошаговое движение | Реализовано, подтверждение шагов вручную |
| 3D | Реальная сцена Three.js на основе планов; высоты условные; GPU-проверка предстоит |
| RU/EN | Интерфейс, названия и 406 непустых исходных описаний переведены; редакторская проверка перевода предстоит |
| GPS | Только передний план; географический слой главного кампуса; без определения этажа |
| Доступность без ступеней | Алгоритм готов; в исходной карте нет подтверждённых атрибутов, поэтому доступный путь не обещается |
| Точное внутреннее позиционирование, автоперестроение | Не реализованы: нужны геопривязка и источник позиции в помещении |
| Расстояние/ETA | Не показываются для немасштабированной схемы |
| Расписание, аккаунт, облачный редактор, подписанные обновления | Не реализованы |

## Структура

| Каталог | Ответственность |
|---|---|
| `src/domain` | Типы данных, Dijkstra, инструкции, поиск, качество GPS, границы карт, реестр языков |
| `src/data` | Отдельные пакеты помещений и наружной географии, проверка входного формата |
| `src/i18n` | Типизированные словари интерфейса |
| `src/components` | SVG, 3D, наружная карта, поиск, отчёт об ошибке, жесты |
| `src/platform` | Геолокация, настройки, системное «Поделиться» и экспорт |
| `scripts` | Импорт, платформенная конфигурация, иконки, браузерная проверка |
| `tests` | 50 проверок данных, маршрутов, GPS и пользовательских сценариев |
| `android`, `ios` | Нативные проекты Capacitor |

Новая тема меняет CSS-переменные, новый поиск не затрагивает граф, новый визуализатор использует тот же `CampusPackage` и `MapHandle`. 3D загружается отдельным модулем обычной сборки.
